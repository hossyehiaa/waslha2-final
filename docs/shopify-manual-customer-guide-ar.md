# دليل ربط متجر Shopify مع Wslahali

## الفكرة

متجرك يظل يعمل على Shopify كالمعتاد. الربط مع Wslahali يجعل الطلب الجديد في Shopify يظهر تلقائياً كشحنة في Wslahali، وبعد ذلك ترجع حالة الشحنة ورقم التتبع إلى Shopify.

## ماذا تحتاج؟

ستحتاج إلى الدخول إلى Shopify Admin الخاص بمتجرك وإنشاء Shopify App للمتجر أو فتح التطبيق الموجود لديك، ثم تجهيز:

| البيانات | الاستخدام |
| --- | --- |
| رابط المتجر الدائم بصيغة `your-store.myshopify.com` | تعريف المتجر |
| Admin API Access Token | قراءة الطلبات وإرسال تحديثات الشحن |
| Shopify App Client Secret | التحقق من أن الطلبات الواردة من Shopify صحيحة |
| اسم ورقم هاتف وعنوان ومدينة الاستلام | تحديد مكان استلام الشحنة |

فعّل فقط الصلاحيات الخاصة بقراءة الطلبات وطلبات التنفيذ وإنشاء الـ fulfillment وfulfillment events. قد يطلب Shopify صلاحية `fulfill_and_ship_orders` حسب إعدادات المتجر.

## خطوات الربط

1. سجّل الدخول إلى حسابك في Wslahali.
2. افتح **Dashboard → Shopify Integration**.
3. اكتب رابط المتجر بصيغة `your-store.myshopify.com`.
4. الصق **Admin API Access Token** في الحقل الخاص به.
5. الصق **Shopify App Client Secret** في الحقل الخاص به.
6. اكتب اسم ورقم هاتف وعنوان ومدينة مكان استلام الشحنات.
7. اضغط **Save and connect**.

بعد نجاح الحفظ، سيقوم Wslahali بتسجيل Webhook الطلبات تلقائياً. لا تحتاج إلى نسخ رابط Webhook أو إنشاءه يدوياً.

## اختبار الربط

أنشئ Order تجريبياً يحتوي على اسم المستلم ورقم هاتفه وعنوانه ومدينة صحيحة. يجب أن يظهر الطلب في لوحة Wslahali كشحنة جديدة برقم تتبع. بعد أن يغيّر فريق Wslahali حالة الشحنة، يجب أن يظهر التحديث في Shopify.

## قواعد الأمان

لا ترسل Access Token أو Client Secret في WhatsApp أو البريد أو أي محادثة عامة. لا تضعهما داخل كود الموقع أو Git. أدخلهما فقط داخل صفحة Shopify Integration في Wslahali. يتم تشفيرهما على السيرفر ولا يتم عرضهما مرة أخرى بعد الحفظ.

إذا تم إلغاء التطبيق أو تغيير Access Token داخل Shopify، يجب تحديث بيانات الاتصال من صفحة Shopify Integration في Wslahali. لا ترسل حقل `shippingCost`؛ تكلفة الشحن يحسبها Wslahali تلقائياً.
