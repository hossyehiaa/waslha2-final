# رسالة جاهزة للعميل — ربط Shopify مع Wslahali

**العنوان: خطوات ربط متجرك Shopify مع Wslahali**

أهلاً بك،

يسعدنا انضمامك إلى Wslahali. تم إنشاء حساب خاص لشركتك على منصة الشحن، ويمكنك من خلاله إدارة الشحنات، متابعة حالات التوصيل، ومراجعة التحصيلات الخاصة بمتجرك.

## أولاً: تسجيل الدخول إلى Wslahali

1. افتح الرابط التالي:
   **https://wsalhali.vercel.app/login**
2. استخدم اسم المستخدم الذي تم إرساله لك.
3. سيتم إرسال كلمة المرور في رسالة منفصلة وآمنة، ولا تشاركها مع أي شخص.
4. بعد تسجيل الدخول، افتح:
   **Dashboard → Shopify Integration**

لن تحتاج إلى إنشاء حساب Shopify Partner، ولن تحتاج إلى استخدام Make أو Zapier أو أي API Key خاص بـ Wslahali لهذا الربط. الربط يتم مباشرة بين متجرك Shopify وحسابك الخاص في Wslahali باستخدام Shopify Custom App خاص بمتجرك.

## ثانياً: إنشاء التطبيق داخل Shopify

يجب تنفيذ الخطوات التالية من حساب Shopify Admin الخاص بالمتجر المطلوب ربطه:

1. افتح **Shopify Admin**.
2. اذهب إلى:
   **Settings → Apps and sales channels**
3. افتح **Develop apps**. إذا ظهرت رسالة تفعيل تطوير التطبيقات، وافق على التفعيل.
4. اضغط **Create an app**.
5. سمِّ التطبيق مثلاً:
   **Wslahali Shipping Integration**
6. اجعل التطبيق خاصاً بهذا المتجر فقط، ثم افتح إعدادات التطبيق.
7. من **Configuration → Admin API integration** فعّل أقل الصلاحيات المطلوبة للتكامل:
   - قراءة الطلبات.
   - قراءة طلبات التنفيذ أو الشحن fulfillment orders.
   - إنشاء وتحديث بيانات التنفيذ والتتبع fulfillment/tracking.
   - إذا طلب Shopify صلاحية إضافية باسم **fulfill and ship orders** أو ما يعادلها، فعّلها لأنها مطلوبة لإرسال رقم التتبع وتحديث حالة الشحنة.

لا تمنح التطبيق صلاحيات لا علاقة لها بالطلبات أو الشحن. لا نحتاج إلى صلاحيات العملاء، المنتجات، المدفوعات، أو إعدادات المتجر إلا إذا طلب Shopify صلاحية ضرورية أثناء إعداد fulfillment.

## ثالثاً: تثبيت التطبيق واستخراج البيانات المطلوبة

1. اضغط **Install app** أو **Install** داخل Shopify.
2. وافق على الصلاحيات التي اخترتها.
3. من صفحة التطبيق، افتح **API credentials**.
4. اضغط **Install app** أو **Reveal token once** حسب ما يظهر في حسابك.
5. احتفظ بالـ **Admin API access token** مؤقتاً في مكان آمن. قد يعرضه Shopify مرة واحدة فقط.
6. انسخ **App client secret** من بيانات اعتماد التطبيق.

**مهم جداً:** لا ترسل الـ Admin API access token أو الـ App client secret عبر WhatsApp أو البريد أو أي محادثة، ولا تضعهما في كود الموقع أو ملف Excel. أدخلهما فقط داخل صفحة **Shopify Integration** في حسابك على Wslahali.

## رابعاً: إدخال بيانات الربط في Wslahali

داخل صفحة **Dashboard → Shopify Integration** أدخل البيانات التالية:

| الحقل | القيمة المطلوبة |
|---|---|
| Store domain | الدومين الدائم بصيغة `your-store.myshopify.com` |
| Admin API Access Token | التوكن الذي أنشأه Shopify للتطبيق |
| Shopify App Client Secret | السر الخاص بتطبيق Shopify |
| Sender/Pickup name | اسم المتجر أو الشخص المسؤول عن الاستلام |
| Sender/Pickup phone | رقم الهاتف المستخدم للتواصل مع الاستلام |
| Sender/Pickup address | عنوان استلام الشحنات |
| Sender/Pickup city | المدينة المسجلة والمفعلة في Wslahali |

استخدم دومين Shopify الأساسي الذي ينتهي بـ `.myshopify.com`، وليس دومين المتجر التجاري أو الدومين المخصص مثل `www.example.com`.

بعد مراجعة البيانات اضغط **Save and connect** وانتظر رسالة نجاح الاتصال. عند نجاح الربط، تقوم Wslahali تلقائياً بتسجيل webhook لاستقبال الطلبات الجديدة من Shopify.

## خامساً: اختبار الربط

بعد ظهور حالة الاتصال بنجاح:

1. أنشئ طلباً تجريبياً واضحاً في Shopify، أو استخدم طلباً تجريبياً منخفض المخاطر.
2. استخدم عنواناً داخل مدينة مدعومة ومفعلة في Wslahali.
3. تأكد من وجود اسم المستلم ورقم هاتفه وعنوانه بشكل صحيح.
4. افتح صفحة الشحنات في Wslahali وانتظر وصول الطلب.
5. عند نجاح الاختبار، يجب أن تظهر شحنة جديدة برقم تتبع Wslahali.
6. بعد تغيير حالة الشحنة في Wslahali، يتم إرسال رقم التتبع وتحديث حالات التنفيذ في Shopify عندما تكون الحالة مدعومة.

الربط يعالج الطلبات الجديدة التي تصل بعد نجاح الاتصال. الطلبات القديمة الموجودة قبل الربط قد لا تتحول تلقائياً إلى شحنات، ويمكن التعامل معها يدوياً حسب الحاجة.

## ماذا يحدث بعد نجاح الربط؟

عند إنشاء طلب جديد في Shopify، تستقبل Wslahali بيانات الطلب، تتحقق من صحة الاتصال، وتمنع التكرار، ثم تنشئ شحنة مرتبطة بالمتجر. يتم احتساب تكلفة الشحن من نظام Wslahali، لذلك لا تعدّل أو ترسل قيمة shipping cost من Shopify.

بعد ذلك يمكنك متابعة الشحنة من لوحة Wslahali. وعند انتقالها إلى حالات الشحن المدعومة، يتم تحديث بيانات التتبع والتنفيذ في Shopify.

## تعليمات أمنية مهمة

- لا ترسل كلمة المرور أو Admin API access token أو App client secret لأي شخص.
- لا تضع التوكن أو السر في رسالة، كود Frontend، GitHub، Google Sheets، أو ملف غير محمي.
- استخدم حساب المستخدم الخاص بشركتك فقط، ولا تستخدم حساب مدير Wslahali.
- لا تحتاج إلى API Key من Wslahali من أجل ربط Shopify.
- كل متجر يحتاج إلى بيانات Custom App الخاصة به؛ لا تستخدم بيانات متجر آخر.
- إذا تم تغيير أو إلغاء التوكن من Shopify، يجب تحديث بيانات الربط من صفحة Shopify Integration في Wslahali.
- إذا ظهرت رسالة خطأ، أرسل لنا نص رسالة الخطأ أو صورة منها بعد إخفاء أي توكن أو سر، ولا ترسل بيانات الاعتماد نفسها.

## في حالة عدم نجاح الاتصال

تحقق أولاً من النقاط التالية:

1. أن الدومين مكتوب بصيغة `store-name.myshopify.com`.
2. أن التطبيق تم تثبيته فعلاً على المتجر.
3. أن الصلاحيات الخاصة بالطلبات وfulfillment مفعلة.
4. أن الـ Admin API token لم يتم إلغاؤه أو تغييره.
5. أن App client secret من نفس التطبيق ونفس المتجر.
6. أن مدينة الاستلام موجودة ومفعلة في Wslahali.
7. أن الحساب المستخدم في Wslahali هو حساب شركتك وليس حساباً إدارياً.

إذا استمرت المشكلة، أرسل لنا اسم الخطوة التي توقفت عندها ورسالة الخطأ فقط، وسنساعدك في إكمال الربط بأمان.
