أهلاً بك،

يسعدنا بدء الربط بين موقعك الإلكتروني ومنصة Wslahali. بما أن موقعك مبرمج بشكل مخصص وليس Shopify، سيتم الربط مباشرة من خلال واجهة برمجية آمنة API، بحيث يتم إنشاء الشحنات تلقائياً من موقعك ومتابعة حالتها حتى التسليم.

## بيانات الدخول إلى حسابك

رابط الدخول:
https://wsalhali.vercel.app/login

اسم المستخدم: يُرسل لك بشكل منفصل
كلمة المرور: تُرسل لك في رسالة منفصلة وآمنة

بعد تسجيل الدخول، يمكنك متابعة الشحنات وبيانات التوصيل من لوحة التحكم.

## المطلوب من مطور موقعك

يرجى إرسال الرسالة التالية إلى مطور الموقع أو مسؤول البرمجة لديك:

نحتاج إلى ربط الموقع مع Wslahali من خلال Backend الموقع، وليس من خلال JavaScript أو Frontend الظاهر للزوار.

رابط الـ API الأساسي هو:
https://wsalhali.vercel.app/api/integrations/v1

من خلال الربط يمكن للموقع:

- جلب المدن المتاحة للشحن.
- إنشاء شحنة جديدة تلقائياً عند تأكيد الطلب.
- الحصول على رقم التتبع وعرضه للعميل.
- متابعة حالة الشحنة.
- إنشاء أكثر من شحنة في طلب واحد عند الحاجة.
- استقبال تحديثات حالة الشحن من خلال Webhook آمن.

سيتم تزويدكم بمفتاح API خاص بهذا الحساب فقط. يجب حفظ المفتاح داخل Backend أو Environment Variables، وعدم وضعه داخل HTML أو JavaScript أو تطبيق Frontend، وعدم إرساله في GitHub أو أي مكان عام.

## بيانات الشحنة المطلوبة

عند إنشاء الشحنة، يجب إرسال البيانات التالية:

- اسم المرسل ورقم هاتفه وعنوانه ومدينة الإرسال.
- اسم المستلم ورقم هاتفه وعنوانه ومدينة الاستلام.
- قيمة التحصيل عند الاستلام COD إن وجدت.
- وزن الشحنة وعدد القطع.
- نوع الخدمة والأولوية عند الحاجة.
- رقم الطلب الداخلي في الموقع.

يجب استخدام كود المدينة الذي يتم الحصول عليه من واجهة المدن، مثل `CAI` أو `ALX`، وليس اسم المدينة فقط.

## مهم بخصوص السعر

لا يتم إرسال قيمة سعر الشحن من موقعك. يتم احتساب تكلفة الشحن وCOD تلقائياً من خلال نظام Wslahali حسب قواعد التسعير المعتمدة.

## منع تكرار الشحنات

عند إنشاء الشحنة، يجب إرسال رقم الطلب مع قيمة `Idempotency-Key` ثابتة وفريدة. إذا حدثت إعادة محاولة بسبب مشكلة في الإنترنت أو انتهاء مهلة الطلب، يجب استخدام نفس المفتاح حتى لا يتم إنشاء شحنة مكررة.

مثال:

```text
Idempotency-Key: order-10001
```

## Webhook تحديث الحالة

إذا أردت ظهور حالة الشحنة داخل موقعك تلقائياً، أرسل لنا رابط HTTPS من موقعك لاستقبال تحديثات الشحن، مثل:

```text
https://your-domain.com/api/wslahali/webhook
```

يتم توقيع التحديثات رقمياً، ويجب على مطور الموقع التحقق من التوقيع قبل تحديث أي طلب. كما يجب تسجيل رقم كل عملية وعدم معالجة نفس الإشعار مرتين.

## اختبار الربط

قبل تشغيل الطلبات الحقيقية، يرجى تنفيذ اختبار واحد بالترتيب التالي:

1. جلب المدن المتاحة.
2. إنشاء طلب تجريبي.
3. التأكد من ظهور رقم التتبع داخل الموقع ولوحة Wslahali.
4. إعادة إرسال نفس الطلب بنفس `Idempotency-Key` والتأكد من عدم إنشاء شحنة ثانية.
5. تجربة تتبع الشحنة.
6. التأكد من وصول تحديث حالة الشحنة إلى الموقع إذا تم تفعيل Webhook.

## ملاحظات أمنية

- لا ترسل مفتاح API أو كلمة المرور في مجموعات أو قنوات عامة.
- لا تضع مفتاح API في كود Frontend أو JavaScript الظاهر للمستخدمين.
- لا تستخدم مفتاح حساب آخر.
- استخدم HTTPS في جميع روابط الموقع والـ Webhook.
- إذا تم تغيير مطور الموقع أو شككت في تسريب المفتاح، أبلغنا فوراً لإيقافه وإصدار مفتاح جديد.
- إذا ظهر أي خطأ، أرسل نص الخطأ أو صورة منه بعد إخفاء أي مفاتيح أو كلمات مرور.
